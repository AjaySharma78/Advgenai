Before you start

  1. Get a free key at console.groq.com → API Keys.
  2. In Colab, click the 🔑 Secrets icon, add a secret named GROQ_API_KEY, paste your key, and switch Notebook access on.
  3. Open the deck to follow along. In the deck: arrow keys move, F is fullscreen, Q shows likely questions, T switches to the chalkboard.
  4. Open the notebook in Colab and run the cells from top to bottom.
