What we build, day by day

Day 1Foundations

What we build
Nothing yet: theory and your first model call.
Tools added
None.
What you learn
Agent vs workflow, the autonomy ladder (L0 to L4), and why we use the minimum autonomy that works.

Day 2First agent

What we build
A web-search agent, step by step: plain LLM, then a workflow, then function calling, then an agent with memory.
Tools added
search_web, then multiply in the Part 6 practice.
What you learn
Messages and roles, short-term memory, a tool is a Python function, the model asks and our code runs, the system prompt, thread ids.

Day 3Your tools

What we build
A trip-planner agent with five tools in class, a step limit and memory, tested on the same three questions. The trip planner notebook grows it to ten tools.
Tools added
extract_page, get_coordinates, get_weather, convert_currency. Then in the trip planner notebook: calculator, get_distance, save_itinerary, send_telegram, send_email.
What you learn
Write tools that return an Error: text instead of crashing, chain tools (coordinates, then weather), and keep memory per thread.

Day 4Your agent

What we build
Your own agent from your own idea, picking 2 to 4 of the ten tools and adding the new one your idea needs.
Tools added
Telegram and email set up and tested, plus one new tool of your own.
What you learn
Plan an agent in three lines (goal, tools, test question), reuse tools, and keep it small with an Error path and a step limit.

By the end of the week you have

  • A trip-planner agent that chooses its own tools, ten in all: web search, page reading, coordinates, weather, distance, currency, maths, saving a plan, Telegram and email
  • State, so it remembers what it has already done
  • Limits, so it stops on its own (steps, time, per tool)
  • Sources, so every answer says where it came from

Before you start

  1. Get a free Google Gemini key at aistudio.google.com/apikey. The trip planner and Day 4 use it, saved as GOOGLE_API_KEY. The Day 1 to 3 notebooks use a free Groq key (console.groq.com → API Keys) saved as GROQ_API_KEY.
  2. In Colab, click the 🔑 Secrets icon, add each key as a secret with the name above, paste the key, and switch Notebook access on.
  3. From Day 3 you also need a free Tavily key (tavily.com), saved as TAVILY_API_KEY.
  4. Open the deck to follow along. In the deck: arrow keys move, F is fullscreen, Q shows likely questions, T switches to the chalkboard.
  5. Open the notebook in Colab and run the cells from top to bottom.
