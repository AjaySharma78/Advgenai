Questions that may come up0:02 to 0:10
Why not train the model on our notes?
Training is slow and expensive, and must be done again for every change. RAG uses the notes as they are today.
Why not paste all the notes in the prompt?
For a small file it works, but it costs about 3,000 tokens per question; for many documents it would not fit.
Can RAG still be wrong?
Yes: the search can miss, or the model can add facts. That is why we grade the answer in Part 4.
What is a chunk?
A small piece of a document, here about 500 characters.
The pipeline
Once, before any question

Split, embed, store

An embedding is a list of 3,072 numbers. Texts with a similar meaning get similar numbers, even with different words.

Questions that may come up0:10 to 0:20
Why 500 characters?
Small enough that a chunk is about one idea, big enough to hold a full answer. The assignment compares it with 1,000.
What is chunk_overlap?
Some text repeated between neighbours, so a sentence cut in half is still whole in one chunk.
How does search find 'similar'?
It compares the numbers of the question with the numbers of every chunk, and returns the closest ones.
Is there a limit on Google's free plan?
100 embedding requests a minute; each chunk is one. If you see RESOURCE_EXHAUSTED, wait a minute.
In code
Parts 1 and 2

Five lines from file to search

chunks = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=100).split_documents(docs) embeddings = GoogleGenerativeAIEmbeddings(model="gemini-embedding-001") vector_store = InMemoryVectorStore(embeddings) vector_store.add_documents(chunks) vector_store.similarity_search("How much can I use the free Groq plan each minute?", k=2)

The question says "how much can I use"; the notes say "8,000 tokens a minute". Search by meaning still finds it.

Questions that may come up0:20 to 0:45, then you code
What is a Document?
A LangChain object: page_content (the text) and metadata (where it came from).
Does add_documents call Google?
Yes, once for each chunk. It takes a few seconds.
What does k=2 mean?
Return the 2 closest chunks.
Is InMemoryVectorStore for production?
No, it is lost when the notebook stops. Real apps use a vector database; the methods are the same.

The agent decides when to look

@tool def search_course_notes(query: str) -> str: """Search the notes of the Advanced Generative AI course. Use it for any question about the course.""" texts = [] for doc in vector_store.similarity_search(query, k=3): texts.append(doc.page_content) return "\n\n".join(texts) rag_agent = create_agent(llm, tools=[search_course_notes], system_prompt="For any question about the course, call search_course_notes and answer ONLY from what it returns.")
Questions that may come up0:45 to 1:05, then you code
Why answer ONLY from the notes?
So the model does not mix what it found with what it guesses.
What if the notes do not say?
The prompt tells it to say so. 'The notes do not say' is a good answer.
Why k=3?
A few chunks give enough to answer without filling the context.
Can the agent search twice?
Yes. If the first search misses, it can try other words: that is the agentic part.
