Questions that may come up0:02 to 0:25

The link needs the word bot in front of the token: api.telegram.org/bot then the token, with nothing between bot and the token.
The chat id list is empty.
You have not sent your bot a message yet. Press Start, send hi, then reload getUpdates.
Telegram says 401.
The token is wrong or was revoked. Copy it again from @BotFather, with no spaces or quotes.
Telegram says 403.
The bot cannot message that chat. Press Start on your bot, and check that you used the chat id (from getUpdates) and not the number in front of the token.
There is no app passwords page.
2-Step Verification is off, or it is a school or work account. Use a personal Gmail account.
The email says the login failed.
You used your normal password. It must be the 16-letter app password, written without spaces.

After @tool the function is a tool object. You test it by hand with .invoke and a dictionary of inputs.

Revoke it: send /revoke to @BotFather and make a new one. For the app password, delete it on the same Google page and create another.
Can the agent email anyone?
It can email any valid address, from your Gmail, but only an address you typed in your own message. A personal Gmail allows about 500 recipients a day, so do not send many.

Can I use a paid API?
Avoid it. Use free services without a card, so everyone can run the notebook.

Questions that may come up0:35 to 1:30
How do I know a tool is ready?
Run it by hand with .invoke and a real input, then with a bad input. It must return a text that starts with Error: and not crash.
My agent never uses my new tool.
Read the docstring as the model would. Say what the tool does and when to use it. Then add one line to the system prompt that names the tool.
The agent invents a tool or a link.
Add to the prompt: your only tools are these names, and never invent a link.
What should I break?
Give a bad link, a city that does not exist, or a vague question. Then check that the agent says what failed and does not crash.
I ran out of time.
Show what works: one tool tested by hand is a good demo. Finish the rest at home and send it to me.
How do I save my work?
File, Save a copy in Drive. Never share a notebook with a key pasted in it.
Where can I see the steps?
Print the Tools used line from the messages of the run, as in the trip planner notebook.
Week 1 recap
What you learned in four days

Week 1 in one slide

1
An agent is a model, tools and a loop. The model decides the steps
In a workflow you write the steps. In an agent the model chooses them, so use the least autonomy that works
2
A tool is a Python function: name, docstring and inputs
The model asks for a tool and our code runs it. Function calling is ask, run, answer
3
A good tool never crashes: it returns an Error: text
Test every tool by hand with .invoke before the agent uses it
4
The system prompt tells the agent which tool to use and when
The trip planner chains tools by itself: coordinates first, then weather. Ten tools, one agent
5
Memory is the messages we keep, and a step limit stops runaways
Same thread id, same memory. A small agent that works beats a big one that does not
