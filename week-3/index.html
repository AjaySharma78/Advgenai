What we build, day by day

Day 1Context engineering

What we build
A search agent you look inside, a memory agent, a summarizing agent, and a guarded page reader.
Blocks used
InMemorySaver, SummarizationMiddleware, ContextEditingMiddleware with ClearToolUsesEdit, @wrap_tool_call, Prompt Guard.
What you learn
What the context is, why it grows, how to keep it small, and indirect prompt injection.

Day 2Long-term memory

What we build
A memory agent that remembers each student in a new thread and never mixes two students up.
Blocks used
InMemoryStore, namespaces, ToolRuntime, context_schema, @dynamic_prompt.
What you learn
Short-term versus long-term memory, and why the user id must come from your code.

Day 3Agentic RAG

What we build
A course assistant that searches the course notes by meaning before it answers.
Blocks used
RecursiveCharacterTextSplitter, GoogleGenerativeAIEmbeddings, InMemoryVectorStore, a search tool.
What you learn
Chunks, embeddings, search by meaning, and grounding checks.

Day 4MCP and the project

What we build
The study assistant, and an eval table against a plain model.
Blocks used
MCPAdapter, await adapter.list_tools(), await agent.ainvoke(), an async @wrap_tool_call, everything from Days 1 to 3.
What you learn
What MCP is, async tools, least privilege for tools, and measuring a RAG agent.

By the end of the week you have

  • A study assistant that answers from the course notes, remembers each student, and reads the official docs
  • The habit of looking at the context: what is in it, what it costs, and what could poison it
  • A comparison with a plain model, in numbers: right answers and tokens
  • Your own small MCP server

Before you start

  1. Groq (console.groq.com → API Keys) as GROQ_API_KEY, every day. Tavily (tavily.com) as TAVILY_API_KEY, on Day 1.
  2. New for Days 3 and 4: a free Google AI Studio key (aistudio.google.com → Get API key) as GOOGLE_API_KEY. We use it only for embeddings.
  3. In Colab, click the 🔑 Secrets icon, add each key with the name above, and switch Notebook access on.
  4. Speed limits: Groq allows about 8,000 tokens a minute and 200,000 a day per model; Google allows 100 embedding requests a minute and 1,000 a day. If a cell ends with RateLimitError or RESOURCE_EXHAUSTED, wait a minute and run it again.
  5. Open the deck to follow along (arrow keys, F fullscreen, Q likely questions, T chalkboard), and run the notebook in Colab from top to bottom.
